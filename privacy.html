Privacy policy

Ledger, a personal expense tracker for Android. Last updated 23 October 2026.

What Ledger reads

  • Notifications from bank and wallet apps that the user has chosen in the app's settings. Notifications from any other app are ignored.
  • Gmail, only if the user connects it, with Google's read-only Gmail scope (gmail.readonly). Ledger only searches for emails from bank alert senders that the user has listed in the app's settings, and only reads those emails.

What Ledger keeps

From each purchase alert, Ledger keeps the parsed details: amount, currency, merchant, date and time, and card name. It does not keep whole emails or card numbers. When an alert can't be read, a short sample (up to 300 characters, with card numbers masked) is kept so the user can write a rule for it.

Ledger does not store Google passwords or Google access tokens. Google Play services provides a short-lived access token for each sync.

Where the data goes

Everything stays on the phone, in the app's private storage. Ledger has no server and no analytics, and it does not share, sell or transfer data to anyone. Data leaves the phone only when the user exports it themselves, for example by sharing a CSV file.

Google user data

Ledger's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to record the user's own purchases in the app on their own phone.

Removing access and data

  • In the app, Settings → Gmail → Disconnect Gmail stops email sync.
  • Google access can be removed completely at myaccount.google.com/permissions.
  • Settings → Delete all data erases every entry, trip and log on the phone. Uninstalling the app also deletes all of its data.
